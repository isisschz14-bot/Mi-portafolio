# 📂 Repositorio en construcción — Bienvenido/a

> *"Los datos públicos son de todos; entenderlos, el reto."*

Este repositorio está **en proceso**. Lo que encontrarás aquí son proyectos de análisis enfocados en **estadística económica y sociodemográfica de México**, construidos a partir de fuentes oficiales de gobierno: INEGI, CONEVAL, Banxico, CONAPO y más.

---

## 🧭 ¿De qué trata esto?

El objetivo es simple: tomar los datos que el gobierno ya publica — en tabulados, microdatos o vía API — y convertirlos en algo que se pueda leer, comparar y entender.

Nada de cajas negras. Todo reproducible, documentado y abierto.

---

## 🔬 Tipo de proyectos 

- 📋 **Explotación de tabulados oficiales** — limpieza, estructuración y análisis de las tablas publicadas por dependencias como INEGI o CONAPO
- 🔌 **Consultas vía API** — extracción automatizada desde fuentes como el INEGI API o el catálogo del DENUE
- 📊 **Visualizaciones** — gráficas, mapas y tablas que traducen variables económicas y demográficas en patrones legibles
- 🔗 **Correlación de variables** — cruce de indicadores para encontrar relaciones entre fenómenos sociales y económicos

## 🏛️ Fuentes de datos

Los proyectos de este repositorio se nutren exclusivamente de fuentes oficiales:

| Fuente | ¿Qué aporta? |
|---|---|
| INEGI | Censos, encuestas, DENUE, API de indicadores |
| CONAPO | Proyecciones de población, índices de marginación |
| CONEVAL | Medición de pobreza, rezago social |
| Banxico | Indicadores económicos y financieros |
| SESNSP | Estadística de seguridad pública |
